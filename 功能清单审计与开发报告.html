二、本次新开发 / 补全的功能

📝 智能出题 (C9)

选知识库+题型(选择/问答)+数量 → AI 生成题目，选项可点选判分、显示答案/解析/来源。接口 POST /api/quiz/generate

✍️ 智能写作 (C12)

填主题(+风格/篇幅/大纲) → AI 基于知识库撰写 Markdown 文章，附引用来源，可一键复制。接口 POST /api/writing/compose

📅 复习计划 (C11)

选知识库+目标+天数+时长 → AI 生成按天递进的复习路线。接口 POST /api/learning/review-plan

🏷️ 自动加工 (A3)

文档上传后 AI 自动生成一句话摘要与关键词标签(存入 description/tags)，受 app.ai.auto-enrich 开关控制

🚫 拒答横幅 (B8)

检索未命中时，回答上方显示橙色警告，提示「答案可能超出知识库范围」

🔗 入口与路由

聊天页用户菜单新增「智能出题/智能写作/复习计划」；新增 /quiz /writing /review-plan 路由

三、暂缓项与下一步建议

A2 卡片导入现有「学习卡片」本就由知识库 chunks 动态派生，无需独立「导入卡片到知识库」环节，概念上已覆盖。

C10 查漏补缺需为每张学习卡片增加「掌握度」字段并在学习时回写，再据此推荐弱项。建议下一轮：StudyCard 加 mastery 字段 + 弱项推荐接口。

C14 MCP/智能体建议独立专项：引入 Spring AI MCP 或 langchain4j-mcp，先做「每日学习提醒 / 知识库每日摘要」定时智能体，再扩展外部工具调用。

四、如何体验

  • 登录 admin / 123456，打开聊天页左侧用户菜单 → 进入「智能出题 / 智能写作 / 复习计划」。
  • 出题：选一个已含示例文档的知识库（如「Java学习」「大模型学习」），生成后即可作答判分。
  • 写作：输入主题（如「Java 集合框架概述」）生成文章，底部展示引用来源。
  • 拒答：在限定某知识库后问与之无关的问题，回答上方会出现橙色警告横幅。
  • 自动标签：上传一篇新文档，处理完成后在「知识库与标签」后台可见 AI 生成的摘要与关键词。
