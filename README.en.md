# RAG Knowledge QA System

**A Java RAG application connecting document ingestion, vector retrieval, streaming answers and source citations.**

[Setup guide](README.md#快速开始) · [Screenshots](README.md#页面预览) · [Architecture](README.md#系统架构)

- Parse, chunk and embed documents in multiple formats.
- Switch between local Ollama models and cloud DashScope models.
- JWT authentication, role permissions, conversation management and operation logs.

**Technology / topics:** Java · Spring Boot · Spring AI · Vue 3 · PostgreSQL · pgvector
